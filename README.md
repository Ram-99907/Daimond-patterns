💎 Diamond Pattern in C
This repository contains a simple C program to print a diamond star pattern using loops.
It is useful for beginners learning pattern printing and nested loops in C.
📌 Program Description
Takes the number of rows as input
Prints a symmetric diamond shape using *
Uses for loops and basic logic
Easy to understand and modify
🧠 Concepts Used
Nested for loops
Spacing and pattern logic
User input using scanf()
